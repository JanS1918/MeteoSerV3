## 🚀 Cómo Usar (Para ti y colaboradores)

### **AL INICIAR**
```bash
# Verificar que sistema está íntegro
python guardrail_integridad.py
# Debe pasar ✅
```

### **DESARROLLAR NUEVO FEATURE**
```
1. Escribe el CÓDIGO (funcional, probado)
2. Verifica que se ejecute sin errores
3. Documenta QUÉ EXISTE (no promesas)
4. Haz commit
   → pre_commit_checklist.py se ejecuta automáticamente
   → Si pasa → OK
   → Si falla → arregla y reintenta
```

### **CADA VIERNES**
```bash
# Auditoría semanal
python SCRIPTS_PATRULLA/AUDITORIA_EXHAUSTIVA_V3.py

```

### **SI ALGO FALLA**
```
Orden de acciones:
1. Pausa todo
2. Lee: MANIFESTO_CODIGO_FUNCIONAL.txt
3. Implementa lo que falta O borra la promesa falsa
4. Re-ejecuta guardrail
5. Continúa cuando pase ✅
```
