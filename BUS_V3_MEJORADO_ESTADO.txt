🎯 SOLUCIONES A LAS 5 GRIETAS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

GRIETA 1: Delta Publishing mata variables estables
  ✅ SOLUCIÓN: Pulso mínimo
     - Cada variable tiene intervalo_minimo (ej: 60s)
     - Se publica aunque no cambie: mantiene "pulso"
     - DatoConHistorico.deberia_publicarse() → Δ > umbral OR tiempo > intervalo

GRIETA 2: Búsquedas ingenuas O(n)
  ✅ SOLUCIÓN: Trie + Índices invertidos
     - BusIndexer con estructura jerárquica
     - flat_map para O(1)
     - indice_por_familia para O(k) sin iterar todo
     - Cache de búsquedas complejas

GRIETA 3: Snapshot arbitrario (sesgo humano)
  ✅ SOLUCIÓN: Basado en varianza
     - BusSnapshotDinamico analiza varianza_historica
     - Solo incluye variables donde varianza > umbral
     - Matemático, no humano
     - 10K variables → 50-100 automáticamente

GRIETA 4: Contención de locks
  ✅ SOLUCIÓN: Queue + single writer
     - BusAsyncWriter con threading.Queue (thread-safe)
     - 100 threads publican sin locks
     - 1 worker thread escribe (sin contención)
     - Latencia de publicar() = O(1) constant

GRIETA 5: IA sin histórico (queries adicionales)
  ✅ SOLUCIÓN: Deque integrado en cada variable
     - DatoConHistorico mantiene deque circular
     - Última 100 muestras automáticamente
     - IA accede directo: obtener_serie_para_lstm()
     - Sin queries BD, sin duplicación

💡 EJEMPLO DE USO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

from ejemplo_bus_v3_mejorado import BusV3Mejorado

# 1. CREAR BUS
bus = BusV3Mejorado(tamaño_cola_escritura=10000, ventana_historico=100)
bus.iniciar()

# 2. REGISTRAR VARIABLES (con configuración Delta)
bus.registrar_variable("Sensores.Ecowitt.Temperatura", 
                       umbral_delta=0.1, 
                       intervalo_minimo_segundos=60)

# 3. PUBLICAR (múltiples threads, sin bloqueo)
for i in range(100):
    bus.publicar("Sensores.Ecowitt.Temperatura", 20.0 + i*0.1)
    # Si Δ ≤ 0.1°C y tiempo < 60s: se filtra (no escribe en disco)
    # Si Δ > 0.1°C o tiempo > 60s: se publica

# 4. BÚSQUEDAS RÁPIDAS (para IA)
serie = bus.obtener_serie_para_lstm("Sensores.Ecowitt.Temperatura", ultimas_n=60)
# Retorna últimas 60 muestras integradas

# 5. SNAPSHOT AUTOMÁTICO (para Dashboard)
snapshot = bus.obtener_snapshot_formateado()
# Solo 50-100 variables "importantes" (varianza > umbral)
# 10.000 variables filtradas automáticamente

# 6. ESTADÍSTICAS
stats = bus.obtener_estadisticas_completas()
print(f"Publicaciones: {stats['publicaciones']['exitosas']}")
print(f"Eficiencia (Delta): {stats['publicaciones']['eficiencia']*100:.1f}%")
print(f"Variables en snapshot: {stats['snapshot']['variables_en_snapshot']}")

# 7. CERRAR
bus.detener()
