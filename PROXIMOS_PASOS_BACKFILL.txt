PASO 2: USAR DATOS PARA BACKFILL DE DEARDORFF V46.5
────────────────────────────────────────────────────────────────────────────────

from core.integration.data_recovery import cargar_datos_recuperados
from core.models.deardorff_v46_5 import ModeloDeardorff

# Cargar datos recuperados
resultado = cargar_datos_recuperados('data/datos_recuperados_20260205_115613.json')
sensores = resultado['sensores']

# Inicializar modelo
modelo = ModeloDeardorff()

# Backfill con datos históricos
for sensor in sensores:
    ts = sensor.get('timestamp')
    t = sensor.get('temperatura')
    hr = sensor.get('humedad')
    
    if all([ts, t, hr]):
        # Calcular T_min con correcciones
        t_min = modelo.estimar_temperatura_minima(t, hr)
        print(f"{ts}: T={t}°C, HR={hr}% → T_min={t_min}°C")

DETALLES TÉCNICOS - CAMPOS DISPONIBLES EN SENSORES
════════════════════════════════════════════════════════════════════════════════

Cada registro de sensor contiene:
  • timestamp/ts: Fecha/hora de la lectura
  • temperatura: Temperatura en °C
  • humedad: Humedad relativa en %
  • presión: Presión atmosférica en hPa
  • velocidad_viento: Velocidad en m/s
  • radiación: Radiación solar en W/m²
  • uv_index: Índice UV
  • [otros campos según configuración específica]

Los datos están validados y listos para usar directamente en:
  → Modelos Deardorff V46.5 (T_min, T_max)
  → Cálculos de evapotranspiración
  → Índices ambientales
  → Análisis de tendencias
